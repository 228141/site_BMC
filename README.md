# site_BMC

Site do **BMC — Bigorna • Martelo • Cruz**, programa de formação de homens da **Igreja em Movimento**.

Encontros: domingos, às 9h — Av. Visconde de Inhomerim, 133 — Mooca/SP
Contato: WhatsApp (11) 9 2013-3747

## Estrutura

```
index.html      página
style.css       estilos
script.js       menu, animações e formulário
img/            imagens (nomes sem espaços nem acentos)
```

## Formulário "Quero participar"

O formulário não precisa de servidor: ao enviar, ele monta a mensagem e abre o
WhatsApp da liderança já preenchido. Para trocar o número, altere
`WHATSAPP_BMC` no início do `script.js` e os links `wa.me` do `index.html`.
